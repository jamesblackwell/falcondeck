Subject: FalconDeck: an open-source Mac workspace for coding agents

Hi Console team,

I'm building FalconDeck, a free, MIT-licensed Mac app for Codex, Claude Code and OpenCode. I thought it might be worth a look for Console.

I wanted a comfortable place to work with coding agents without spending the whole day in a terminal or changing my editor. FalconDeck shows the conversation, tool output and approval requests in one app, using the agents and accounts you already have.

There's also an iPhone/iPad companion for following a task and replying when you're away from your desk. The agents still run on your Mac, which needs to stay awake and online for remote access.

It's an early 0.1.x project, but I use it daily and am actively improving it. You can download the Mac app and try it directly; agent subscriptions or API usage are paid through the usual providers.
