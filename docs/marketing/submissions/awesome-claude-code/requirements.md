# Awesome Claude Code recommendation

Checked 5 October 2026. This is the Awesome Claude Code list discussed earlier.

Use the [Recommend a Resource web form](https://github.com/hesreallyhim/awesome-claude-code/issues/new?template=recommend-resource.yml). The maintainer explicitly requires the web UI, not a PR or gh CLI, and says recommendations must be created by humans. The companion file is preparation material: write your own final recommendation and personally verify the attestations. It does not pre-check them.

Eligibility is either 14 days since the first default-branch commit plus subsequent active development, or 100 stars. Local history starts on 15 March 2026 and shows later development, so FalconDeck appears to meet the age/activity route without needing 100 stars. The bot makes its own remote-history determination. Submit one resource at a time; acceptance and even a response are discretionary.

Suggested category: **Alternative Clients**. Describe the actual Claude Code integration, though FalconDeck also supports other agents. The list favours Claude-specific resources, so its multi-agent scope could affect selection. Do not claim exclusivity.

The description must be factual, one line, without emojis or addressing the reader. The form allows 10–500 characters and 1–3 sentences. Author/link fields and the complete checklist are in form.md. GitHub currently recognises FalconDeck's MIT licence. An agent account is still needed to use it; no adoption figures are supplied.

Before submission, read the list yourself and compare existing alternative clients and remote-control tools. Confirm distinctness, links and the conduct rules yourself. The final optional checkbox is a reading trap and must remain unchecked.
