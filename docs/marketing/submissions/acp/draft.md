# PR body

I'm the author of FalconDeck and would like to add it to the Desktop and Web section.

FalconDeck runs coding agents against local project folders and provides a Mac UI for conversations, tool output and approvals. It supports ACP agents such as OpenCode, alongside separate integrations for Codex and Claude Code. A paired iPhone/iPad app connects to the same host to follow tasks and respond remotely.

The project is MIT licensed, with Mac downloads and a getting-started guide available:

- Website: https://falcondeck.com
- Source: https://github.com/jamesblackwell/falcondeck
- Getting started: https://github.com/jamesblackwell/falcondeck/blob/main/docs/GETTING-STARTED.md
- Agent integration docs: https://github.com/jamesblackwell/falcondeck/blob/main/docs/HARNESSES.md
